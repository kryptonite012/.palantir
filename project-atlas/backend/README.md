# atlas-api — Project Atlas backend

Python package `project_atlas` (distribution `project-atlas`): the FastAPI service, database
migrations, job runner and CLI (`atlas serve | create-admin | backup | verify-backup | offline-check | migrate`)
for PROJECT ATLAS, an offline-first intelligence and data operations platform.

See the repository README and `docs/` for installation, architecture and security documentation.
Run the tests with `python -m pytest` from this directory.
