# Synthetic demonstration data (Project Atlas)

**All files in this directory are SYNTHETIC.** People, organizations, e-mail addresses (`example.invalid`),
phone numbers, documents and coordinates are fictional and generated deterministically by
`scripts/generate_sample_data.py` (seed 20251027). Every tabular record has `record_origin=SYNTHETIC`.

See `expected_results.json` for the deliberately planted defects and the expected analytical results,
and `docs/user-guide.md` for the walkthrough that uses them.
